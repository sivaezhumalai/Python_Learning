# Python Learning Repository

This repository contains a comprehensive collection of Python learning materials, projects, and daily challenges designed to help you master Python programming from the basics to advanced concepts.

## Overview

This project is part of the **Python Ultimate Course** and serves as a practical learning environment where you can:

- Learn core Python concepts through hands-on scripts
- Build real-world mini-projects
- Practice daily coding challenges
- Access course materials and resources

## What You'll Find

### Core Python Learning Scripts (01_scripts)
- **Functions**: Function basics, parameters, return values, styling
- **Strings**: String manipulation, cleaning, validation
- **Numbers**: Basic operations, rounding, random module, validation
- **Working with data**: Lists, dictionaries, exception handling

### Mini Projects (02_projects)
Each project simulates real-world applications:

1. **User Registration System**
   - Implements secure user registration with validation
   - Uses: Functions, exception handling, data structures

2. **Expense Tracker**
   - Manages personal expenses with tracking capabilities
   - Focuses on data organization and analysis

3. **Mini Bank**
   - Simulates basic banking operations
   - Handles transactions and account management

### Daily Challenges
Jupyter notebooks containing daily coding exercises to practice and reinforce concepts learned.

### Course Materials
Comprehensive PDFs and resources covering:
- Python syntax and cheat sheets
- Data handling techniques
- Course syllabus for 100-day Python learning plan

## How to Get Started

1. **Clone this repository:**
   ```bash
   git clone https://github.com/sivaezhumalai/Python_Learning.git
   cd Python_Learning
   ```

2. **Set up the environment:**
   ```bash
   # The project includes a virtual environment
   source .venv/bin/activate  # On Windows: .venv\\Scripts\\activate
   ```

3. **Explore the scripts:**
   - Start with the basic scripts in `python-ultimate-course/01_scripts/`
   - Follow the logical progression from simple to complex topics
   - Refer to solution files in `02_projects/*/solution.py` for complete implementations
